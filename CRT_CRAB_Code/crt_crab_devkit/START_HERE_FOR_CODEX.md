# 给开发 Agent / Codex 的开工指令

你现在负责开发一款暂名《屏幕群岛 / CRT CRAB》的复古低模像素游戏。开发依据是 `docs/DEVELOPMENT_MANUAL.md`，美术依据是 `docs/references/user_style_reference.png`。**先完整阅读二者，再开发。**

最重要的两个不能改的设定：

1. 360°、上下多层、立体错落排列的复古 CRT 电脑堆叠是游戏的核心场景，必须真实 3D 可见，不准退化成一排电脑或单个选关画面。
2. 玩家操控的螃蟹始终在各台电脑的**屏幕画面内部**；只在屏幕世界间跳转，不能在电脑实体外壳、键盘或缝隙间爬行。

优先选择 Godot 4.x，使用 `.glb` 低模资源与 SubViewport 实时屏幕世界。分阶段实现 P0（4 台电脑 + 至少两块可互传的可玩屏幕 + 可玩螃蟹 + 双层镜头）、P1（3 层、12 台以上的 360° 电脑堆）、P2（多个屏幕切换及存档）、P3（解谜与战斗）。每阶段实际运行、验证并报告；绝不能只有一张模拟图或模型展示。

用户明确不接受低质量 Flash 平面风、假 3D、静态贴图冒充玩法、只堆模型而没有游戏性。第三方模型请先核实许可；需要用户登录下载时不要规避授权。完整的验收条款、候选模型链接、镜头架构、玩法和代码结构均在手册中。

现在开始，先给出简短可执行的文件/模块计划，然后直接创建并运行 P0 项目。首次报告必须清楚展示：① 电脑堆叠的立体性；② 螃蟹真的在屏幕里面跑；③ 内部跟随镜头；④ 至少一次屏幕间切换。若无法运行某部分，如实说明，不要假装已完成。
