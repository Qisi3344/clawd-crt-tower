# 给 Codex 的执行任务｜ARCHIVE 美术接入

请读取本素材包的 `README_先看.md` 和 `docs/ARCHIVE_素材位置与Godot接入说明.md`，再检查仓库 `Qisi3344/clawd-crt-tower` 当前 `main` 分支。游戏工程位于 `CRT_CRAB_Code/crt_crab_devkit/`。请**实际接入 ARCHIVE 档案仓库视觉素材，不要只回答“建议/已完成”**。

## 硬性要求

1. 只动 ARCHIVE 的 2D 背景/无碰撞装饰，不改其 1024×640 探索拓扑，也不碰其他五关的现有玩法、美术。
2. `00_reference` 只是画风示意，绝不能把包含整张楼梯与 CRT 边框的概念图直接当背景使用。
3. `01_backgrounds` 的远景与中景是**未核实无缝**的源图；需要实际检查并制作场景匹配版本。中景已有楼梯等假可行走构件，必须裁剪/处理/对齐真实几何后才能用。
4. `02_props/split_png/` 的 12 张透明 PNG 分区摆放：`upper` 检索桥，`main` 重压归档大厅，`lower` 破损记录仓。背景和道具绝不能影响箱石、重压板、真实梯子、真实终端、出入口或角色。
5. 保留 320×240 单视口、整数像素角色镜头和现有 CRT 塔，保留存档兼容、九箱、持续压力输入与回访。
6. 保留原始大图，做一致的游戏尺寸化处理；不要直接把 200–350px 的道具以 1:1 塞进 320×240 画面。
7. 真正运行 Godot：展示 3 个分区的 320×240 实机截图以及玩家在新画面中行走的片段，给出安装脚本和可复现检查。不得用概念图代替游戏实际截图。

## 修改点

- `assets/pixel/archive/`：放置处理后的素材与原图。
- `scripts/world_backdrop.gd`：在 ARCHIVE 的专属视觉分支接入远景中景，不再叠加原有重复柜墙；其他 5 关保留原行为。
- `scripts/side_world.gd`：增加 ARCHIVE 专属、无碰撞装饰的装配节点或独立 `archive_dressing.gd`，绑定 12 件道具到 3 个区域附近真实可用的位置。
- 可新增数据驱动的摆件清单；不改 `data/levels/archive_01.json` 的关键机关和地形逻辑。

## 完成标准

提交代码和美术并附三层画面实机对比、背景边缘检查结果、角色可读性检查、性能说明，以及改动文件清单；若有素材瑕疵或未处理的接缝，逐条报告，禁止宣称全部完成。
