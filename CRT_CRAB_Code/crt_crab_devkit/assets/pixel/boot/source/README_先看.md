## 三层地图

- **upper（y=0–112）上层维护灯带**：吊灯、风扇、检修设备与远处支架。不要给画面加假的可走桥或可爬梯。
- **main（y=112–288）中央电源大厅**：核心视觉为电源环；配电柜、服务器、保险丝柜和少量备用电池。起点 `(48,208)`，关键地标约 `(240,144)`。
- **lower（y=288–640）回访线路井**：管线、备用电池、废置设备、检查面板、卷曲电缆；更暗，但能看清角色和已开放通路。

详细坐标、贴图方案及保护项见 `docs/`。
