## 三层背景应如何制作

1. **远景**：使用 `background/POPUP_far_source.png` 作为远处失控数字城市的纹理源。它已包含巨型 CRT、远方浮窗、天空和数字云。应当柔化和压暗、轻微视差，避免亮度抢掉角色及机关。它是单幅插画，不保证横向无缝。可按地图镜头做完整采样或重新绘制横向延伸片段，而不是强制 Stretch 全图。
2. **连续中景**：只以 `reference/POPUP_mid_concept_REFERENCE_ONLY.png` 为风格与建筑参考。请直接绘制连续墙体、叠窗边框、管线和地面连接部位，**不要裁三个窗口立面再循环铺墙**。从一个区域到另一处墙体仍要有合理连接。游戏内的真实平台和门始终在中景之前渲染。
3. **道具层**：以 `props/source_crops/` 单图为母版，`game_candidates/` 为初始分辨率参考；根据当前可见镜头的画面密度调尺寸。静态道具不添加碰撞体、不遮挡玩家和真实机制，重复摆放需控制数量。

## 图与游戏的对应关系（尤其别踩坑）

- 原中景和场景概念图画有桥梁、梯子、广告窗口。它们是视觉设计参考，**不是碰撞地图**。
- 弹窗框体可以成为建筑外形，但不会自动成为交互面或平台；必须服从现有碰撞结构。
- 背景里不要画出和真门、可操作开关、可抓梯子高度相似的假机关。
- 层级推荐：远景 < 中景 < 非碰撞装饰 < 可行走平台/箱石/角色 < UI；具体 z_index 以现有代码为准。
- 对 `world_backdrop.gd` 新增 POP-UP 专属路径，`side_world.gd` 装配独立非碰撞装饰节点；保留现有 ARCHIVE 与 BOOT 的实现。
- 不修改 `popup_01.json` 的机关、坐标、剧情条件、传送、存档；此前已经修好的地图探索路线不变。

## 接入验收（只需要最小闭环）

- 上/中/下三层以及主要岔路各有一张真实游戏截图，重点是看**连续背景、视差、道具落地与可读性**。
- 用实际 320×240 CRT 画面检查，不要用超高清美术源图截图冒充游戏画面。
- 检查左右极端镜头、上下转层镜头时远景有没有空洞、断层或重复破绽。
- 不需要重写旧机关或扩玩法；各关卡存档、主线、宝箱必须照常运行。
- 不要提供“通过 QA 就等于美术完成”的结论。美术好不好看要看截图。
