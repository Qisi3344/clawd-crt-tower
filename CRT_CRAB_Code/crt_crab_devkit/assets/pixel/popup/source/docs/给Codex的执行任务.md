# 给 Codex｜POP-UP 弹窗区美术集成任务（仅本关）

请先解压并阅读 `README_先看.md` 和 `docs/素材位置与接入说明.md`，查看 `manifest.json`，然后直接在仓库 `Qisi3344/clawd-crt-tower` 的 Godot 工程中实施。**这是一轮美术接入，不是玩法策划，不要扩大范围。**

工作范围仅 `POP-UP / popup_01`（1024×768、320×240 CRT 视口）；既有 BOOT、ARCHIVE 和后面三关不要动。地图机关、敌人、旧存档、跨屏传送、箱子、密钥、保险丝、回环、脚本行为保留。

1. **远景**：把 `background/POPUP_far_source.png` 合理裁取成有空间感的远景，控制粉紫亮度，做缓慢视差。未验证无缝，禁止直接重复/强拉伸并声称无缝。
2. **中景**：用两张 `reference/*REFERENCE_ONLY.png` 作为视觉风格参考，**重新组合与绘制连续的场景建筑**，贴合五个真实区域，不能把概念图硬矩形裁切后等间距排列。远景中可留浮窗、损坏 CRT 和窗口都市，但中景墙地面衔接要自然。
3. **路边摆件**：可使用 `props/source_crops/*.png` 的透明源和 `props/game_candidates/*.png` 小图。12 件物品按主题少量摆放，无碰撞，避免挡住真实机关、梯子、能量门与螃蟹。滚动条、线束梁不能造成假可攀爬/假可落脚视觉。
4. **现有地板美术**：仅允许按 POP-UP 的视觉统一改变贴图表现，不改地形几何和碰撞。
5. **效果**：突出故障广告大厅的巨型弹窗、保险室的重叠窗口、供电竖井的纵向层次和底部缓存碎片。不要变成满屏粉色的广告海报。

验证：跑真实 Godot，提交中层、上层、底层、跨层镜头各一张实机截图，并做一次短距离运行时移动检查。必要时修美术接缝，不得绕到玩法系统去。说明修改文件、哪些图被实际使用、哪些仅作参考，以及剩余局限。

注意：包内未提供已通过 Godot 验收的正式无缝中景；设计参考图含假楼梯和桥架，不可直接贴为地图。**接入前应由 Codex 根据原画处理连续中景。**
