## 包内位置

- `source/`：绘制的场景风格概念参考（包含宣传板，因此严禁整张作为游戏背景）。
- `game/far.png`：1024×768 连续远景（低对比机房/废机柜，完整画布，不循环拼片）。
- `game/mid-continuous.png`：1024×768 透明连续中景（后墙机柜、管道、设施轮廓）。**不会在这里画假的站立平台和梯子**。
- `game/props/`：12 件独立 64×64 透明像素 PNG；`game/props-atlas.png` 同款整合图集。
- `game/terrain-style-reference-16px.png`：新地板材质的 16px 风格样板（需根据现有真实碰撞地形调整，不可整图铺设）。
- `preview/`：原布局与 320×240 模拟取景参考，**不是 Godot 实机画面**；含灰色平台与薄荷色梯子叠加，用于确认可见范围。
- `manifest.json`：原图路径、12 件道具、区域尺寸、真实机关坐标。
- `docs/给Codex的执行任务.md`：可以直接交给 Codex 的工作单。

## 核心原则

上层是工业吊装轨道，中层是分拣大厅，下层是电子废料坑与磁吸井，右侧是维护竖井。让旧 CRT 屏幕、线圈、线缆与电路废料构成场景识别，而不只是一般垃圾堆。原地图已存在压机、可逆输送带、磁吸钢块和数据重构，背景只是为这些机关服务。
