## 关键限制

- 游戏保持现有 A / B / C 三路信号机制、绝缘水道、蜂桥、光纤、单视口和旧存档，不调整地图玩法。
- 本地素材使用粗像素绘制，低对比背景与更明亮的玩家/机关形成层次；不要因美术参考海报的霓虹效果而覆盖交互元素。
- 美术参考图带有海报文字和示意平台，绝对不作为可玩地图贴图，也不可从海报硬裁平台和梯子使用。
- `game/mid-continuous.png` 是**完整连续墙面**，不能拆成 48px 矩形后按固定间距重复。
- 道具属于背景装饰，不要给原来没有的碰撞，不要被误认为可交互开关；严格避开机关操作路线。
- 交付前 Codex 必须实际运行 Godot，给出上层 A、中层 HUB/B、上层 C、下层水道的真实截图和移动检验；仅图片加载成功不等于美术过关。

文件变更范围、推荐使用方式及可视化验收见 `docs/接入说明.md` 和 `docs/给Codex的执行任务.md`。
