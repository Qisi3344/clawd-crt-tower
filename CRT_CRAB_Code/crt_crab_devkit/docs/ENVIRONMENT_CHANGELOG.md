# 电脑塔周边环境升级

日期：2026-11-05。基线 `bcd0fe203fe1808684b8d572326a6ef91846e4eb`，开发分支 `codex/tower-surroundings`。设计依据为 [周边场景升级策划书](ENVIRONMENT_BRIEF.md)，实测见 [ENVIRONMENT_QA.md](ENVIRONMENT_QA.md)。

## 实际落地

- 左维修区：真实桌体、开架、转椅、终端、键盘、台灯、纸箱、锤子；原创维修背板、便笺、摆臂灯、电路板、小风扇及带支撑的实体牌。
- 右电玩区：两台真实低模街机、一台贩卖机、一台票机；原创斜玻璃待机图、实体机头牌、饮料陈列架和九个立体饮料罐。两张待机 PNG 四秒切换，无额外游戏关卡或 SubViewport。
- 后供电区：两个工业机柜改作储存柜、一个配电机柜、少量真实管件；补盘位、黄绿 LED、支撑管架及接到原 CRT 插口的地面供电线。
- 上部与外围：有底座的梁柱、开口电缆桥、灯轨、八块有真实厚度的工业板；扩充外围地台，中央原底座保持原样，前方留空。

新模型来自 Kenney 官方四个 CC0 包。20 个源模型完成归档/规范化，其中 16 种进入场景，共 26 个实例。原始文件、独立许可、优化 GLB 和逐项散列/面数见 [素材记录](ASSET_CREDITS.md)。未引入 npm、Python 运行依赖或新的 Godot 插件。

## 场景与交互边界

`surroundings_root.tscn` 只由主会话挂入一次。四个分区独立成场景，每种主要模型有自己的 `.tscn`；`environment_zone.gd` 沿用现有 `Craft` 补小结构，`environment_prop.gd` 加载真实 GLB 并共享压暗材质，`environment_surroundings.gd` 管理位置、遮挡与微动态。没有继续向 `ExteriorDressing` 堆砌内容。

三层十二台 CRT、其布局/机型/下层键盘、旧装饰及两屏关卡数据均未修改；内屏仍为 320×240 / 4:3，螃蟹只有原来的 CharacterBody2D。外围不加入碰撞、可拾取物、玩家或输入处理。没有添加音乐、外部音效，也未使用目录里的 MP3。

Tab 默认观察半径由 29 调整为 35、高度由 16 调整为 20，让四周进入画面；游玩聚焦与跨屏路径保留。活动玻璃中心/四角、观察模式塔中心/边角受保护；相机到目标的线段被外围物体包围盒阻挡时，按物件临时隐藏并在离开后恢复。包围盒包含导入网格和其附属陈列/盘位，梁柱各自处理。远景没有完整封闭墙。

微动态只有风扇低速旋转、机柜 LED 低频跳变、街机两张静态纹理切换。Esc 的“环境微动态”可停用；素材署名同在暂停菜单。装饰无实时阴影，只有一盏低能量工位灯；材质和灯光无需 Bloom。
