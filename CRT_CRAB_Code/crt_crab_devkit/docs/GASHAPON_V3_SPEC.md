# CRT CRAB · 扭蛋机 v3 精确建模修复要求

基于当前 `scripts/pet_gashapon_machine.gd` 修改。坐标采用 Godot 局部坐标：Y 向上，+Z 为正面，X 为左右。单位均为 Godot 3D 单位。

保留现有六款宠物扭蛋、配色、猫耳和场景摆放位置。

## 1. 修改机身与玻璃罩比例

| 参数 | 当前值 | 修改目标 |
|---|---|---|
| 主体宽度 X | 3.15 | 3.85 |
| 主体高度 | 2.50 | 3.20 |
| 主体深度 Z | 2.50 | 3.15 |
| 玻璃罩宽度 X | 5.10 | 3.50 |
| 玻璃罩高度 Y | 4.26 | 2.84 |
| 玻璃罩深度 Z | 4.02 | 3.02 |
| 玻璃罩中心高度 | 5.05 | 4.82 |
| 顶盖中心高度 | 7.15 | 6.24 |

建议局部几何参数：

- 主体中心 `(0, 1.80, 0)`，尺寸 `(3.85, 3.20, 3.15)`。
- 玻璃罩中心 `(0, 4.82, 0)`，球体缩放半径 `(1.75, 1.42, 1.51)`。
- 顶盖中心 `(0, 6.24, 0)`，半径 `(1.85, 0.25, 1.57)`。
- 猫耳最高点控制在 Y≈7.05。
- 整机宽约 3.85，高约 7.05。

玻璃罩底部约为 Y=3.40，与主体顶部接合。底部加宽并加高后，整机不再头重脚轻。

## 2. 玻璃材质

当前玻璃 Alpha=0.035，几乎不可见。

修改为：

- 玻璃基础 Alpha：0.10
- Fresnel 边缘 Alpha：最高 0.42
- Roughness：0.08
- IOR：1.45（如使用支持折射的材质）
- 玻璃颜色：`#E3DCEB`
- 玻璃壁厚视觉目标：0.035
- 边缘添加 2 条宽度约 0.025 的弧形高光
- 禁止用整片白色半透明球体模拟磨砂玻璃

建议使用自定义 Spatial Shader 控制 Fresnel，兼容当前 Godot 渲染器。

必须能清晰看到内部六款宠物，同时具有明确的球形玻璃边缘。

## 3. 重新制作真实出蛋口

当前机身主体是完整盒体，前面的出口只是额外拼接的方块。

**必须改成真正中空的外壳和开孔结构。**

出口参数：

| 属性 | 数值 |
|---|---|
| 出口中心 X | -0.58 |
| 出口中心 Y | 1.215 |
| 出口正面 Z | 1.575 |
| 开口宽度 | 1.30 |
| 开口高度 | 1.47 |
| 开口范围 X | -1.23 至 0.07 |
| 开口范围 Y | 0.48 至 1.95 |
| 取蛋仓向内深度 | 0.85 |
| 外壳壁厚 | 0.15 |

要求：

- 机身前面板由开孔周围的实际网格组成。
- 不允许在完整盒体前面贴一个黑色假洞。
- 取物仓底面与机身连为一体。
- 出口圆角半径约 0.12。
- 出口挡板嵌入开孔，可以向内翻转 55°。
- 前面板、挡板、取物仓不能出现悬空、穿插或明显接缝。

## 4. 内部出蛋机械结构

制作完整的：

**球仓 → 导流漏斗 → 选球盘 → 滑道 → 取物仓**

建议尺寸：

| 部件 | 参数 |
|---|---|
| 导流漏斗 | 上口宽 1.65，下口宽 0.90，高 0.45 |
| 选球盘 | 直径 1.35，厚 0.18 |
| 选球槽 | 每次容纳 1 颗扭蛋 |
| 内部滑道 | 宽 1.25，净高至少 1.30 |
| 滑道侧壁 | 厚 0.08，高 0.16 |
| 通道出口 | 与前方取物仓实际连通 |

储蛋区底部不能使用一整块实心板封死出蛋位置。

用真实网格建造滑道，允许使用 Path3D + Tween 控制扭蛋运动，但动画路径必须经过实际通道。

建议扭蛋中心运动节点：

```text
P0 (-0.55, 3.65, -0.25) 储蛋仓
P1 (-0.55, 2.86, -0.25) 选球机构
P2 (-0.55, 2.45,  0.10) 滑道起点
P3 (-0.55, 1.90,  0.36) 内部下降
P4 (-0.55, 1.34,  0.75) 滑道末端
P5 (-0.55, 1.17,  1.12) 取物仓
```

这些点是初始设计坐标，必须按实际模型尺寸微调，并通过剖视检查。不能让扭蛋穿过实心面板。

## 5. 六款宠物扭蛋

- 仓内展示缩放由当前 `0.50` 调整为约 `0.34`。
- 不再按 3×2 两排整齐悬空陈列。
- 改为 3+2+1 前后交错的自然堆积。
- 每颗扭蛋必须有底部支撑或与其他扭蛋接触。
- 兔兔长耳必须计算进通道净空。
- 滚落时允许小幅摇晃，不要让耳朵强行穿过滑道壁。
- 六款宠物原始独立模型保持不变，只调整机内实例缩放。

## 6. 出蛋动画时序

从旋钮触发到扭蛋到达取物仓，目标总时长约 2.5 秒。

| 时间 | 动作 |
|---|---|
| 0.00–0.35s | 粉色旋钮旋转 90° |
| 0.35–0.70s | 选球盘转动并释放 1 颗 |
| 0.70–1.15s | 扭蛋从储蛋仓进入滑道 |
| 1.15–2.10s | 扭蛋沿内部通道向出口移动 |
| 2.10–2.50s | 扭蛋落入取物仓，轻微弹跳并停止 |

增加机械咔嗒声、球体滚动声和最后的落蛋音效。

不要求完整物理仿真，但必须是连续运动，不能直接在出口生成一颗扭蛋代替全过程。

先做测试用按钮触发出蛋，不需要开发完整抽奖概率、晶体扣费和存档系统。

## 7. 验收条件

1. 球罩最大宽度不得超过机身宽度的 110%。
2. 玻璃必须能看到明显的边缘反射和高光。
3. 出蛋口必须是真实开孔，不是贴在机身外面的盒子。
4. 隐藏机身侧板后，能够看到完整连续的出蛋通道。
5. 实际播放一颗扭蛋从球仓到取物仓的完整动画。
6. 动画过程中不能穿模、瞬移或让扭蛋悬空。
7. 提供正面、侧面、背面及内部剖视截图。
8. 保留现有复古游戏厅、电脑塔和屏幕关卡，不修改无关系统。

**注意：不要只修改数值然后宣布完成。必须实际运行并检查模型比例、出蛋通道几何与动画。**

完成标准：一台比例协调、玻璃质感明确、机械路径真实连通的原创低模猫咪扭蛋机。
