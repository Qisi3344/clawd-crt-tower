# 屏幕群岛 / CRT CRAB — P0 + P1

本轮交付一个 Windows 原生可玩原型，优先证明双层世界和跨屏连续性。

1. 使用 Godot 4.x Compatibility、GDScript。外层是独立 3D 世界，12 台程序化 CRT 分三层朝不同方向摆放，三种机壳；玩家不能进入外层。
2. 一个 480×360 SubViewport 渲染当前 3D 微关卡，通过 ViewportTexture 赋给活跃 CRT。邻机使用各自待机图，不运行 12 份物理世界。
3. 唯一 CharacterBody3D 螃蟹复用 clawd-motion 的形体参数：陶土橙、圆角方身、双钳、单排四腿。添加实际碰撞、跳跃、闪避、攻击与受击反馈。
4. 两个真实微关卡：BOOT 的信号节点教程与 ARCHIVE 的敌人/文件碎片。传输点使用 JSON 连接配置；完成后可以回访，保存机关、战斗与位置进度。
5. 内部相机平滑跟随；外部相机平时聚焦屏幕，切换时绕阵列拉远、转向新设备再靠近。Tab 为阵列观察，拖动环绕，恢复时回到活跃屏幕。
6. 简洁中文 HUD、上下文 E 提示、暂停菜单、声音开关、减少动态；键盘导航。采用 game-ui-ux 的容器/锚点和事件驱动 HUD。
7. 先做 Godot 导入/解析检查，再用真实引擎验证碰撞、输入、开关门槛、击杀、死亡、往返保存、暂停、相机与唯一控制权。保存实际渲染截图。

美术依据：已完整阅读本包手册与五张参考图。以用户更偏好的《绝区零》两张图为主：黑灰机壳、厚重玻璃边框、圆形旋钮/扬声器、少量贴纸标识、错层电视塔和有克制的屏幕光；薄荷色电脑堆与像素城市图只辅助空间层次和屏幕玩法。界面用炭黑/奶白和一个酸黄色强调，不复制参考图里的商业 UI、角色或标志。螃蟹保留陶土橙。

边界：本轮不冒称六关、三谜题或最终 Boss 已完成。clawd-motion 是形体与动作参考，SVG 切片渲染器不作为游戏的 3D 引擎。原图路径为 `docs/参考图/`，不是手册旧路径 `docs/references/`。
