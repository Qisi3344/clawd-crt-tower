## 可运行入口

Windows 双击根目录 `PLAY.cmd`。本机已下载并实际运行 Godot 4.7.2；源码入口为 `project.godot` / `scenes/main.tscn`。其他电脑可先用 `tools/setup.ps1` 或自己的 Godot 导入工程。首次启动脚本自动生成引擎导入缓存。

## 已实装

- 外层为真实 3D、三层十二台 CRT，朝向覆盖 360°；桌面机、窄一体机与电视式机壳。机身、玻璃开口、键盘、通风条、旋钮、线缆、扬声器均为实体网格。Tab 拉远后可拖动观察背面与侧面。
- 只有一个 480×360 活跃 SubViewport，拥有独立 World3D。只有当前 ScreenWorld 的螃蟹接受控制，WorldShell 里没有螃蟹。十台待机设备使用独立签名图；离开的可玩屏幕保留最后的缓存帧。
- 独立内部跟随相机；外部相机始终以当前 CRT 为主体。跨屏用 1.35 秒空间环绕转场，输入锁定，关卡内入口到入口，无实体爬出屏幕。减少动态选项将转场压至 0.35 秒。
- 螃蟹按指定 clawd-motion 比例立体重建：陶土橙、双钳、单排四腿。真实 CharacterBody3D 移动、碰撞、跳跃、短冲、挥钳、受击闪烁、三点生命与当前关卡入口重生。
- BOOT：信号终端解锁接口、可跳阶梯、移动教学；ARCHIVE：追踪弹跳病毒、预警后冲刺病毒、两击击杀、清除后拾取记录。两块屏幕可往返。
- JSON 定义设备、关卡描述与连接图；存档保存全局生命、屏幕、位置、权限、记录与死亡敌人。磁盘先写临时文件再替换。损坏的 JSON 可安全回到新游戏。
- 中文 HUD、交互提示、暂停/继续、音效/动态设置、保存退出、F3 性能信息。真实窗口在 1280×800 与 720×900 下截图复核；窄屏单独调整 UI 尺寸与相机距离。失焦自动暂停。
- 对各设备的重复键帽/通风条/边条使用 MultiMesh，仍保留按整台设备处理遮挡的能力。

## 实际验证证据

- Godot 4.7.2 headless 编辑器导入通过。
- 无窗口引擎测试 28 项通过：`artifacts/qa-headless.json`。
- Windows OpenGL Compatibility 真实渲染测试 30 项通过：`artifacts/qa-visual.json`；`artifacts/visual-errors.log` 无运行错误。
- 测试通过 Input action 进入真实物理与交互处理，不直接伪造通关状态；覆盖移动/跟随、碰撞、跳跃落地、锁门、开关、暂停、转场输入冻结、A→B→A、唯一控制权、敌人击杀、受击无敌、死亡重生、回访状态、磁盘读写和损坏存档恢复。
- QA 禁用玩家正式存档读写；磁盘验证使用按进程号隔离的临时测试文件。
- `artifacts/01-boot.png`：屏幕内螃蟹；`02-array.png` / `03-array-back.png`：阵列不同视角；`04-transfer.png`：实际跨屏中段；`04-archive.png` / `05-record.png`：战斗区与记录；`06-portrait.png` / `07-pause.png`：720×900 与暂停菜单。
- 本机渲染设备为 RTX 5060 Ti。预热后的截图采样多为 57–60 FPS，约 650–865 draw calls、84–88 MiB 引擎静态内存；初始加载帧 FPS 明显更低。这里只是本机瞬时采样，不代表低配置性能基准或长期稳定帧率。

## 未完成与限制

- 手册 P2/P3 的六关、文件复原谜题、旋转接线谜题、故障时序、最终 Boss 与第一章结尾尚未制作。BOOT 的单开关是技术教程，不能计作完整信号连线谜题。
- CRT 与关卡仍是程序化美术原型；尚未达到商业作品材质、贴纸叙事、动画和环境精度。没有从第三方模型站下载资源。
- 敌人目前为轻量原型行为，没有完整寻路、复杂受击动画或 Boss；相机采用方向可微调的跟随，而非完整自由环绕。
- 设置选项当前会话有效，未独立持久化。退出自动保存与磁盘恢复通过代码和 QA 覆盖；尚未做多小时人手游玩、异常断电或跨机器实测。
- PC 键鼠为本轮目标。竖窗口布局通过检查，但没有触屏操作、移动端导出或网页构建。没有将竖窗口截图冒称手机端已可玩。

下一阶段先让用户确认实际操控、电视塔比例与美术方向，再扩展六屏状态机与真正的三种谜题，避免在视觉方向未确认时堆完整章节内容。
