# CRT CRAB 新版侧视切片：实装与验证

更新：2026-11-05。当前主规范为外层 `CRT_CRAB_Code_B` 三份文件；旧手册和历史 3D 原型的完成情况不能代替本版验收。

后续外围环境升级已落地，新增真实 Kenney CC0 模型和四分区；本文件下方 M0～M3 的“第三方模型 0”与旧性能表保留为历史切片记录。**当前实物、最新测试和性能以 [ENVIRONMENT_QA.md](ENVIRONMENT_QA.md) 为准**；[改动与明确未完成项](ENVIRONMENT_CHANGELOG.md)、[当前素材表](ASSET_CREDITS.md)。

## 交付边界

本轮完成 M0 仓库审计/回退点、M1 单屏闭环、M2 BOOT + ARCHIVE 可玩往返，并整合 M3 的原创低模样板美术。不是完整第一章，没有将十台待机设备冒称十个关卡。

- 当前入口：Windows 双击 `PLAY.cmd`；Godot 4.7.2 + GDScript + OpenGL Compatibility。
- 保留三层十二台 360° CRT、外部镜头、上层无键盘/底层保持原状。新增机型/装饰建立在原结构上。
- 玩法为真正的 CharacterBody2D / Camera2D / 320×240 SubViewport；不是以图标在背景上移动，也没有在外壳中创建第二只螃蟹。
- 当前有四个真实宝箱：BOOT 启动宝箱、BOOT 远端奖励、ARCHIVE 主线密钥、ARCHIVE 可选奖励。比首要两屏要求增加了一个回访奖励，用来验证跨屏信号的实际用途；不是首章九箱已经完成。

## 状态语义

- 木箱压住 BOOT 的普通板后开门；角色重量 1 也能压普通板，但无法隔空通过门。
- ARCHIVE 重石重量 2，推离高台后落在重板上；板实际被压住时产生 `signal_archive_gate`。该信号既控制本关门，也控制 BOOT 的远端门。
- 离开后保存石块位置；回访/磁盘重载后由实际物体恢复持续状态，不靠“只记录曾经触发过”假开门。
- R 复位当前箱石谜题并重算其持续信号；不重置宝箱账本、晶体、密钥或已领取奖励。死亡回当前屏幕检查点，已有机关状态保留。
- 晶体能在 BOOT 终端兑换回血，满血时不会消费。四个宝箱全部记录后出现“两屏切片完成”反馈。
- 存档迁移保留完整 legacy_progress 和独立 `.v1-backup`；原 3D 坐标不强行解释为 2D 坐标。新版规则下的钥匙、宝箱从新地图开始，不将旧原型奖励虚报为新谜题通关。

## 实际验证

Godot headless 导入通过。新 `--qa` 使用 `tests/sideview_qa.gd`，不再运行历史 3D 用例。

- headless：69 项检查通过，`artifacts/sideview-qa-headless.json`。
- Windows 真实 GPU 渲染：70 项检查通过，`artifacts/sideview-qa-visual.json`。最终 `sideview-visual-errors.log` 为空；退出时也没有此前加速音频测试留下的资源警告。
- 正常输入验证：走跳过沟、推/拉、压板开门、越过箱子、爬梯、开箱、出门、ARCHIVE 重石落板、可破坏障碍、可选宝箱、回 BOOT 取跨屏奖励，再回 ARCHIVE。
- 独立场景验证：数据虫两击受伤/死亡、重量阈值、无连锁掉血、暂停/阵列输入冻结、快速重复 E、错误出生点拒绝、转场中目标失效后的实时画面/控制恢复。
- 存储验证：宝箱防重复、R 前后两种压力状态、真正磁盘读写并重新实例化世界、持久石块与信号重现、损坏 JSON 回退、实际 v1 文件迁移与独立备份。
- QA 和性能模式均禁用正式存档访问。磁盘用例使用 `qa-side-<进程号>.json`，验证完仅清理它及其测试备份。
- 测试不直接写解锁旗标或宝箱账本伪造通关。战斗及重量阈值用例单独定位角色用于隔离验证，之后恢复正常检查点；两屏机关/宝箱/往返路线由游戏输入完成。

## 独立性能采样

设备 GPU：NVIDIA GeForce RTX 5060 Ti。引擎 4.7.2，1280×800，一块 320×240 活跃内部画布；非活动关卡不运行 AI/物理。重复设备和线缆使用共享网格及 MultiMesh。

`--perf` 不使用固定时间步，以墙钟各采样 2.5 秒，强制真实 OpenGL 绘制并读回 GPU 画面。下面是包含读回开销的离屏渲染循环，不是交互游玩的稳定 FPS 保证。固定时间步 QA 报告里的 FPS 不能拿来当性能结论。

| 视角 | 实测渲染循环/秒 | 绘制+读回中位数 / P95 | draw calls | 引擎静态内存 |
|---|---:|---:|---:|---:|
| active | 52.8 | 16.57 / 18.96 ms | 774 | 81.8 MiB |
| front | 60.0 | 16.51 / 17.55 ms | 678 | 81.8 MiB |
| back | 59.9 | 16.55 / 17.92 ms | 690 | 81.8 MiB |

原始结果在 `artifacts/performance.json`。尚未测低配置、多小时运行或移动 GPU。
