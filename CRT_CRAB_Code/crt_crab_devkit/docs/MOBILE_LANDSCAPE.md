# 横屏移动端状态

用户要求只做横屏。项目设置 `display/window/handheld/orientation=0`；触屏模式下若收到竖屏尺寸，暂停整个关卡、释放所有触点并显示旋转提示，也可切回键鼠。手机没有竖屏玩法布局。

操作由真实 Godot ScreenTouch / ScreenDrag 驱动。左侧摇杆负责移动和攀爬，右侧为跳跃、螯击、互动；推拉同时按住互动与摇杆。每根手指单独持有动作。暂停、地图、阵列、剧情、跨屏、切模式及失焦都会释放虚拟输入。六个 CRT 的完整画面投影均检查在顶部 HUD 与底部操作区之间。

当前交付包含源码与桌面可运行版本。桌面原生触摸事件已完成双指、按住推拉、跳跃、攻击和 BOOT—ARCHIVE—BOOT 往返；这些记录不能替代 Android/iOS 真机验收。当前环境未配置 Android SDK/JDK、ADB 或 iOS 构建工具链，因此本轮没有声称交付 APK、AAB 或 IPA。

后续导出使用与项目引擎匹配的 Godot 导出模板与目标平台工具链，在导出页建立 Android/iOS 预设并完成签名；iOS 需要相应的 Apple 构建环境。安装到实际手机后，仍需验证横屏与系统旋转、同时双指推拉/跳跃、手指移出按钮与中途抬指、应用切后台再回来、连续跨 CRT、存档重启和声音。设备、系统版本、稳定帧率与温度都需记录，不能把固定时间步 QA 的 FPS 当成手机性能。
