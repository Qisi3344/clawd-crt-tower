# CRT CRAB · 宠物扭蛋抽取系统 v1

基于现有 `pet_gashapon_machine.gd` 和六款 `PetCapsule` 模型开发。保留现有机身、玻璃罩和出货口，不重新建模。

## 1. 储蛋仓展示

仓内六颗扭蛋保持自然堆叠，采用当前 3+2+1 的交错布局。

- 保持物体之间有接触，不悬空、不穿插。
- 扭蛋平时静止，不需要持续运行 RigidBody3D。
- 每次抽取时，六颗扭蛋一起轻微晃动。
- 晃动位移范围 ±0.035 单位，旋转 ±5°。
- 晃动持续 0.55 秒，分 3 次左右衰减后恢复原位。
- 不需要从储蛋仓中真实取走某颗扭蛋，仓内展示数量保持不变。

## 2. 抽取概率

```gdscript
const COMMON_RATE := 0.72
const RARE_RATE := 0.25
const HIDDEN_RATE := 0.03

const RARE_PITY := 4
const HIDDEN_SOFT_PITY_START := 13
const HIDDEN_HARD_PITY := 20
```

普通：猫猫、狗狗，各占普通池 50%。

稀有：仓鼠、兔兔、小熊，各占稀有池 1/3。

隐藏：金色发光猫猫。

保底逻辑：
- 连续 3 次没有稀有及以上，第 4 抽强制稀有及以上。
- 第 13–19 抽，隐藏款概率每抽增加 5 个百分点，即第 13 抽 8%，第 19 抽 38%。
- 第 20 抽强制隐藏款。
- 概率提升部分从普通池扣除，稀有基础概率保持 25%。
- 先判定隐藏款，再判定稀有保底，最后判定稀有和普通。
- 获得隐藏款时，两个保底计数器都清零；获得稀有款只清零稀有保底计数器。

## 3. 抽取动画

整体时长约 1.5 秒：

| 时间 | 动作 |
|---|---|
| 0–0.25s | 旋钮转动 90°，播放机械咔哒声 |
| 0.15–0.70s | 仓内六颗扭蛋轻微摇晃 |
| 0.70–0.95s | 出货口挡板打开，播放掉落声 |
| 0.95–1.25s | 在出口内部生成已抽中的宠物扭蛋，向外移动并小幅弹跳 |
| 1.25–1.50s | 扭蛋停止，挡板复位，显示抽取结果 |

不再使用当前 `ROUTE` 和 `TIMES` 驱动仓内扭蛋完整滚落。

出口生成位置初始建议：

```gdscript
Vector3(-0.58, 0.88, 1.20)
```

最终展示位置：

```gdscript
Vector3(-0.58, 0.88, 1.93)
```

使用 `Tween` 控制移动，按实际模型检查碰撞和穿插。

- 普通款：简单白色提示。
- 稀有款：粉色或青绿色短暂光圈。
- 隐藏款：金色闪光、短暂电子粒子和专属音效。

禁止用强 Bloom 遮挡扭蛋。

## 4. 抽取结果与存档

新增独立的扭蛋收藏数据：

- 每种宠物的拥有数量
- 总抽数
- 距离上次稀有及以上的抽数
- 距离上次隐藏款的抽数
- 最近抽取记录

抽到重复宠物允许重复记录，后续用于图鉴和兑换系统。

使用 `RandomNumberGenerator`，不要使用固定随机种子进行正常抽取。动画播放前先确定抽取结果，并安全写入存档，防止退出游戏重复领取或丢失奖励。

## 5. 交互与费用

提供可实际操作的扭蛋交互界面，不能只是测试场景里的自动演示。

当前版本先设 `COST_CRYSTALS = 0`，用于免费测试抽取与收藏；界面价格必须同步显示为免费测试，不得继续显示需要支付 100 晶体。

正式收费和晶体来源后续再配置，避免目前关卡产出的晶体不足以体验保底。

## 6. 验收

1. 仓内六颗扭蛋自然堆积，抽取时有轻微晃动。
2. 仓内扭蛋不沿滑道移动，出口单独生成奖励模型。
3. 六款都可以正确抽取，外观与实际稀有度一致。
4. 连续 4 抽必有稀有或以上，20 抽必有隐藏款。
5. 抽取过程不能连续点击触发重复出货。
6. 收藏数据及保底计数在重启后正确恢复。
7. 提供普通、稀有、隐藏三种抽取演示和概率测试结果。

不修改 CRT 电脑塔、游戏厅其他装饰与屏幕解谜系统。
