## H2 / H3：六个真实可玩屏幕

新增房间使用各自的坐标、出生点、箱石、敌人与机关记录；每次只挂载一个 SideWorld、一个可操控 Clawd。房内短淡切与跨 CRT 的 EXIT / LINK / UNLOCK / ENTER 分开。坏房间 ID、越界保存位置和阻塞出生点有安全回退。

|---|---|
| BOOT / 0 | 原布局、启动宝箱和远端宝箱不删；RECYCLE 完成后新增反向快捷链路 |
| ARCHIVE / 5 | 原布局、钥匙宝箱、隐藏宝箱和真实重石信号保留；新增 POP-UP 出口 |
| POP-UP / 4 | 广告回廊、重叠窗口竖井、可选缓存夹层；飞蛾预警弹、三档反射、真实定时弹窗碰撞、保险丝、恢复供电；备用脉冲避免提前打死飞蛾后软锁 |

专项行为测试另验证：180° 反弹反杀、无飞蛾备用解法、蜗牛压板、蜘蛛线可切且给临时单向桥通电、仓鼠被压机击败、河狸只啃指定裂板、鳗电脉冲经绝缘线路给线圈充电。

## H4：菜单到送达闭环

- 原 `FrontEnd → begin_adventure()` 成功初始化后播 15 秒模拟桌面开场；同一消息 ID `user-presence-001`，原文“还在吗？”。先正常合作，再发送失败，Clawd 敲框、自己按 REPAIR、自己跳入端口。
- 自然完成、真实 Esc 输入跳过、重复点击、失焦暂停、存盘失败重试均通过。继续完成的冒险不重播开场。
- ERROR 仅在三个当前输入与全部必要主线条件成立后提交送达事务；SIGNAL READY 不提前送达。核心关闭不是任意宝箱触发。
- 结局先保留已修复核心及送达状态，再播放真实塔镜头和原模拟桌面，显示“已送达”，Clawd 回复“在呀！我回来啦！”。像素字体缺少的蟹表情改用真实角色图标展示。
- 结局后有继续探索、回看结局、返回菜单；存档重启后回 ERROR，Boss 不复活、结局不重复。九个宝箱可在本轮通关与回访中全部取得。
- 已修复权限和源电路当前状态独立：回 ARCHIVE 按 R 真正关闭 A，但不收回 ERROR 权限；可重新推石修好。
- HUD/主菜单动态统计本工程的 9 箱、6 段修复；Tab 显示每屏锁定/可进入/已修复及 User 消息状态。

`tools/verify.ps1` / `tools/verify.ps1 -Visual` 会同时检查 JSON 报告与日志，出现 `SCRIPT ERROR`、`ERROR`、`FAIL` 即失败，不能只信旧报告中的 passed。原扭蛋测试现在先安全跳过新增开场，再测试暂停状态；未改变扭蛋商店或概率逻辑。

六关 `*-gameplay.gif` 从测试过程中真实 GPU 的 320×240 活跃视口每 6 帧采样而来，采样为固定 60 步流程的 10 帧/秒录像。不是概念图，也不是原生实时 FPS 证据。`chapter-qa-visual.json` 带原始帧数。主线机关和收集通过移动、跳跃、推拉、攀爬、E/J 输入，不写解锁/宝箱旗标冒充通关；继承的旧测试在战斗/伤害小用例中有明确定位夹具。开场由独立菜单用例验证，完整冒险 QA 从同一新档 BOOT 安全点开始。

`ecology-qa-visual.json` 与敌人专项 GIF 是明确的孤立房间夹具，不作为“从菜单通关”的替代证明。全塔五视图、横竖窗口开场、送达与回复、九箱回访截图均附在证据目录。

性能使用同一 RTX 3050、1280×800、无 fixed-fps 的 2.5 秒墙钟采样，并强制 GPU 绘制/图像读回。旧提交和当前报告分别为 `baseline/performance.json` 与 `performance.json`。读回包含额外开销，不能把采样次数或 QA FPS 写成稳定游戏 FPS；两轮采样存在缓存、调度和温度噪声。

最终连续成对采样中，基线/当前的 active、front、back 绘制调用分别同为 382 / 1292 / 1277；静态内存约增加 3.1 MiB。绘制读回中位数由 6.293 / 9.475 / 8.857 ms 变为 6.994 / 12.415 / 11.865 ms，当前约慢 11–34%。这项测量不等于交互 FPS，尚不能保证低配设备的长时间表现；需要后续持续性能采样和优化，不能将首版写成“性能完全无回退”。

最后另对 Tab 六屏状态面板做了 1280×800 与 720×900 的真实 GPU 边界检查，修正六行状态扩展后右侧文字裁切，截图为 `overview-final-1280.png` / `overview-final-720.png`。

## 当前完成度与待继续的细节

这是可通关、可回访、可恢复的**六关第一版**。尚未完成正式美术精修、首次玩家难度/时长调优、所有动物逐帧专用动画、实体手柄实测、键位重映射、移动端触控与导出。场景机理按优先级落地，不能声称策划中的每项演出细节均已最终定稿。

特别说明：策划的 55–77 分钟是设计目标，尚无首次玩家实测；回看开场的独立菜单、ARCHIVE 纵向附房、部分环境交互与表现细节可在此版基础上继续迭代。现有扭蛋与服装收藏未作为主线门槛。
