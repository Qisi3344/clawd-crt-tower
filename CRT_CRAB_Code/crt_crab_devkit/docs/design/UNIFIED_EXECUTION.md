# 本轮统一执行规则

用户最新决定：手机横屏操作，不开发竖屏玩法。触屏模式下竖屏暂停、释放触点并提示横屏，提供切回键鼠入口；桌面窄窗保留基本 UI 容错。

1. UI 阶段保护旧地图；地图阶段允许空间迁移，不改变速度、跳跃、攻击和重量数值。保留九箱 ID、六段通信、衣橱、扭蛋与原剧情。
2. 操作掌握与谜题完成分开：真实移动、起跳落地、箱石移动、实际攀爬、成功交互、攻击命中、阵列进出分别完成教程；压板/数据重构仍是世界目标。
3. controls.cfg 存操作偏好与提示开关；冒险存档保存教程与探索。切模式只补操作位置说明，不重复做谜题。新游戏只清冒险教程。
4. 输入由一个路由器聚合。触点单独拥有动作，抬指不释放其他来源；GUI 点击不会通过全局 Input 轮询造成攻击。暂停/转场/地图/失焦释放虚拟输入。
5. Tab 为 CRT 阵列；M 为当前关内部地图。均只查看，不提供任意传送。地图、导航及门口标识使用同一批 area/connection 数据。
6. 布局版本与存档版本分开。v4 物体、房间与坐标按明确 offset/ID 迁移；无法安全恢复位置时回该区域检查点，不能凭空完成机关。迁移前备份。
7. R 复位当前机关组；永久捷径、宝箱、外观与剧情保留。持续信号依据实际源物体重算。SIGNAL 三支路是本地校准，不撤销旧 B/C。Boss 保留 A→B→C 顺序。
8. 先验证 RECYCLE 的连续三层、三岔、回环和返回地标，再扩展其他关。控制、存档、碰撞、镜头与真实 GPU 分别验证。手机实机和人工首次玩家体验无法由桌面模拟替代。
