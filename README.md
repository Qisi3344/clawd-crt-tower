# CRT小蟹闯塔记

当前默认启用复古游戏厅氛围：全场轻三渲二、实体灯具与屏幕局部光、房间围合及稀疏墙地面装饰，音响改为粉紫并加宽约 15%。主菜单设置与暂停菜单可关闭“游戏厅氛围”。[改造对比与验收](CRT_CRAB_Code/crt_crab_devkit/docs/ARCADE_HALL_UPDATE.md)。

当前工程位于 `CRT_CRAB_Code/crt_crab_devkit/`，以该包的完整手册和 `docs/参考图/` 五张图为准。

Windows 打开 `CRT_CRAB_Code/crt_crab_devkit/PLAY.cmd`。引擎、操作、验证与已知限制见工程内 README.md。

当前新增电脑塔周边维修、电玩、供电与梁架四区；真实模型来源、对照图和回归记录见 [环境升级记录](CRT_CRAB_Code/crt_crab_devkit/docs/ENVIRONMENT_CHANGELOG.md) 与 [验收证据](CRT_CRAB_Code/crt_crab_devkit/docs/ENVIRONMENT_QA.md)。

第二阶段加入正式主菜单、四款衣橱、晶体消费、v3 存档兼容与三段传送，详见 [交付与验证](CRT_CRAB_Code/crt_crab_devkit/docs/STAGE_TWO_REPORT.md)。
